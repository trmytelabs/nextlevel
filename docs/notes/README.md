# Development notes

Working notes kept as a record of how Next Level was built. They describe the project at the time they were written, so details in them are often out of date (stage names with years, the generated score, two sabers, a fixed 128 BPM timeline, the earlier rsync deploy). The repository's main [README](../../README.md) describes the current build.

| File | What it is |
|---|---|
| `CONTEXT-PROMPT.md` | The briefing used to start new AI coding sessions on the project mid-way through |
| `NIGHT.md` | An overnight work report from the first big build |
| `EDITORIAL.md` | An editorial pass on making the "five generations" story legible |
| `REVIEW-ERAS.md` | A code and test review of every stage (findings referenced from the code as `REVIEW-ERAS E1-4` and similar) |
